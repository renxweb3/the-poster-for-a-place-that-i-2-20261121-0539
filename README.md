THALVARA — a travel poster for a place that isn't there. A small program that paints one 1024×1024 PNG: a dusk coast where the sea climbs the sky in a single great waterfall, a low sun, a lone sailboat, and the place's name set in large hand-drawn stroke lettering. Pure TypeScript, zero dependencies, no network — it rasterizes the whole poster with its own tiny software renderer and writes its own PNG bytes.

## Run it

```sh
node main.ts
```

This writes `/output/entry.png` (1024×1024, under 1 MiB).
